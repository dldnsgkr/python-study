### 🏋 CAPSTONE A — 로그 분석 CLI

대용량 접근 로그(수 GB)를 스트리밍으로 처리해 통계를 내는 명령줄 도구를 만드세요.

- 제너레이터 파이프라인으로 **메모리 사용량이 파일 크기와 무관**하게 유지될 것 (08)
- `argparse`로 기간·상태코드·출력형식 옵션 (16)
- 결과 모델은 `frozen dataclass`, 상태코드는 `IntEnum` (12)
- 파싱 실패 줄은 커스텀 예외로 수집해 마지막에 요약 리포트 (13)
- 여러 파일은 `ProcessPoolExecutor`로 병렬 처리 (17)
- `mypy --strict` 통과 + pytest로 파서 단위 테스트 (15, 18)

---

**🟢 설계 힌트**

```python
def read_lines(paths) -> Iterator[str]: ...
def parse(lines) -> Iterator[Entry | ParseError]: ...
def filter_entries(entries, since, status) -> Iterator[Entry]: ...
def aggregate(entries) -> Report: ...

# main은 이 네 개를 연결만 한다 — 각 단계는 독립적으로 테스트 가능
report = aggregate(filter_entries(parse(read_lines(paths)), since, status))
```

파이프라인 각 단계를 **순수 함수 + 제너레이터**로 유지하면 테스트에서 리스트를 넣어 리스트를 받는 형태로 검증할 수 있습니다.

### 🏋 CAPSTONE B — 미니 ORM

SQLite 위에 동작하는 아주 작은 ORM을 직접 구현하며 파이썬의 객체 모델을 끝까지 써 보세요.

- `Field`를 **디스크립터**로 구현해 타입 검증과 기본값 처리 (10, 11)
- `__init_subclass__`로 모델 클래스가 정의되는 순간 테이블 메타데이터 수집 (10)
- `Query` 객체가 `__iter__`를 구현해 **지연 실행**되게 (08, 11)
- 메서드 체이닝: `Model.objects.filter(...).order_by(...).limit(10)`, 반환 타입은 `Self` (15)
- 트랜잭션을 `@contextmanager`로 (11)
- 연결 누수를 `weakref`와 `tracemalloc`으로 점검 (19)

---

**🟢 디스크립터 골격**

```python
class Field:
    def __set_name__(self, owner, name):     # 클래스 정의 시 자동 호출
        self.name = name
        self.private = f"_{name}"

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self                       # 클래스에서 접근하면 자기 자신
        return getattr(obj, self.private, self.default)

    def __set__(self, obj, value):
        if not isinstance(value, self.type):
            raise TypeError(f"{self.name}: {self.type.__name__} 필요")
        setattr(obj, self.private, value)
```

`__set__`이 있으면 **데이터 디스크립터**가 되어 인스턴스 `__dict__`보다 우선합니다. 10파트의 속성 조회 순서를 다시 보세요. `property`도 정확히 이 메커니즘으로 만들어져 있습니다.
