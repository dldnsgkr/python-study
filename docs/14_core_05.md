# 05 · 딕셔너리와 집합

`hash contract · views · collections`

dict는 파이썬의 중추입니다. 객체 속성(`__dict__`), 모듈 네임스페이스, 클래스 본문, 키워드 인자가 전부 dict입니다. 3.7부터 **삽입 순서가 언어 명세로 보장**됩니다.

## 해시 규약

키가 되려면 **해시 가능(hashable)**해야 합니다. 규약은 단 하나: `a == b`이면 반드시 `hash(a) == hash(b)`. 역은 성립하지 않아도 됩니다(해시 충돌).

*해시 가능성*

```python
hash((1, 2))          # OK  — 튜플은 원소가 모두 해시 가능하면 해시 가능
hash([1, 2])          # TypeError: unhashable type: 'list'
hash(frozenset({1}))  # OK

class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def __eq__(self, other):
        return isinstance(other, Point) and (self.x, self.y) == (other.x, other.y)
    def __hash__(self):
        return hash((self.x, self.y))     # __eq__ 를 정의하면 __hash__ 도 같이!
```

**⚠️ Gotcha**

`__eq__`만 정의하면 파이썬은 `__hash__`를 **자동으로 None으로 만들어** 해당 객체를 해시 불가능하게 바꿉니다. dict 키나 set 원소로 쓰던 클래스에 `__eq__`를 추가하는 순간 런타임 에러가 터집니다. `@dataclass(frozen=True)`를 쓰면 둘 다 자동 생성됩니다.

## dict 실전 메서드

*dict*

```python
d = {"a": 1, "b": 2}

d.get("z")                 # None (KeyError 없음)
d.get("z", 0)              # 기본값
d.setdefault("c", []).append(1)   # 없으면 넣고, 있든 없든 그 값을 반환

d.keys(), d.values(), d.items()   # 뷰 객체 — 원본과 실시간 연동, 복사 아님
dict(zip(keys, values))
{k: v for k, v in pairs if v}     # dict 컴프리헨션

d | {"c": 3}               # 3.9+ 병합 (새 dict)
d |= {"c": 3}              # 제자리 갱신

d.pop("a")                 # 값 반환하며 삭제
```

*collections*

```python
from collections import defaultdict, Counter, deque, ChainMap

groups = defaultdict(list)
for user in users:
    groups[user.team].append(user)     # 키 존재 확인 불필요

Counter("mississippi").most_common(2)  # [('i', 4), ('s', 4)]
Counter(a=3) + Counter(a=2)            # Counter({'a': 5})

q = deque(maxlen=100)                  # 양끝 O(1), 링버퍼로도 사용
q.appendleft(x); q.popleft()

ChainMap(cli_args, env_vars, defaults)  # 우선순위 있는 설정 조회
```

**⚠️ Gotcha**

`defaultdict`는 **읽기만 해도 키를 만듭니다**. `if groups["없는팀"]:` 한 줄로 빈 리스트가 삽입됩니다. 조회 전용 코드에서는 `.get()`을 쓰거나 `dict`로 되돌려 넘기세요.

## 집합

*set*

```python
a, b = {1, 2, 3}, {3, 4}

a | b      # 합집합       a.union(b)
a & b      # 교집합       a.intersection(b)
a - b      # 차집합
a ^ b      # 대칭 차집합
a <= b     # 부분집합 여부

empty = set()      # {} 는 빈 dict!
frozenset(a)       # 불변 집합 → dict 키로 사용 가능
```

순서를 유지하면서 중복만 제거하려면 `list(dict.fromkeys(xs))`를 쓰세요. `set`은 순서를 보장하지 않습니다.

**🖥 REPL 퀴즈 — 05-1 · 뷰 객체**

```python
>>> d = {"a": 1}
>>> ks = d.keys()
>>> d["b"] = 2
>>> list(ks)
>>> for k in d:
...     d[k + "!"] = 0
```

뷰는 스냅샷이 아니라 **살아 있는 창**입니다. 그리고 순회 중 크기 변경은 금지됩니다. 순회하면서 수정해야 한다면 `for k in list(d):`처럼 키를 먼저 복사하세요.

3. LRU 캐시를 `dict`의 삽입 순서 보장만 이용해 구현하세요(`move_to_end` 없이).
4. `__eq__`는 정의했지만 `__hash__`를 정의하지 않은 클래스를 set에 넣어 보고 에러 메시지를 확인하세요.

---

**🟢 2번 예시 답**

```python
def diff(old: dict, new: dict) -> dict:
    old_keys, new_keys = set(old), set(new)
    common = old_keys & new_keys
    return {
        "added":   {k: new[k] for k in new_keys - old_keys},
        "removed": {k: old[k] for k in old_keys - new_keys},
        "changed": {k: (old[k], new[k]) for k in common if old[k] != new[k]},
    }
```

`set(dict)`는 키 집합을 만듭니다. `d.keys()` 뷰 자체도 집합 연산을 지원해서 `old.keys() & new.keys()`로 바로 쓸 수도 있습니다.
