# 파이썬 완전 습득 워크북

Notion 임포트 방법 — 이 폴더의 md 파일 전체를 한 번에 선택해 Notion 좌측 하단 Import → Markdown & CSV 로 올리면, 파일명 순서(00, 01, 02 …)대로 파트별 페이지가 만들어집니다.

표시 방식 — 코드블록은 언어별 하이라이트, 표는 표 블록, 콜아웃(함정·JVM 노트·Tip)은 이모지 볼드 헤더, REPL 출력과 실습 정답은 구분선으로 나뉜 정답 블록으로 들어옵니다. 정답을 가리고 풀고 싶으면 임포트 후 정답 블록을 선택해 토글로 감싸면 됩니다.

## 목차


### 기초 · 처음 배우기

- **B0** 시작하기 — 파이썬이라는 도구
- **B1** 변수 — 값에 이름 붙이기
- **B2** 기본 데이터 타입 — 값의 종류
- **B3** 여러 값 담기 — 리스트·튜플·딕셔너리·세트
- **B4** 흐름 제어 — 조건과 반복
- **B5** 함수 — 나만의 명령 만들기
- **B6** 클래스 — 나만의 데이터 종류 만들기
- **B7** == 와 is, 그리고 그다음

- **10** 클래스 — 속성 조회의 규칙
