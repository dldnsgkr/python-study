# 02 · 숫자 — 무한 정밀도와 부동소수점

`int · float · Decimal · Fraction`

파이썬 `int`는 **크기 제한이 없습니다**. 오버플로가 없으니 `long`도 `BigInteger`도 필요 없습니다. 대신 큰 수 연산은 느립니다.

*정수*

```python
2 ** 1000        # 302자리 정수, 오버플로 없음
1_000_000        # 언더스코어 구분자 허용
0b1010, 0o17, 0xff        # 2/8/16진수 리터럴
int("ff", 16)             # 255
divmod(17, 5)             # (3, 2)
```

## 나눗셈 세 종류

| 연산 | 결과 | 비고 |
| --- | --- | --- |
| `7 / 2` | `3.5` | 항상 float |
| `7 // 2` | `3` | 바닥 나눗셈(floor) |
| `-7 // 2` | `-4` | 0이 아니라 **-∞ 방향**으로 내림 |
| `-7 % 2` | `1` | 결과 부호가 **제수**를 따른다 |

**☕ JVM 개발자 노트**

Java는 `-7 / 2 == -3`, `-7 % 2 == -1`(0 방향 절단)입니다. 파이썬은 `-4`, `1`. 음수 인덱스 계산이나 순환 큐 로직을 JVM에서 옮겨올 때 이 차이가 조용한 버그가 됩니다. 파이썬 규칙은 `a == (a // b) * b + (a % b)`를 항상 만족합니다.

**🖥 REPL 퀴즈 — 02-1 · 부동소수점**

```python
>>> 0.1 + 0.2
>>> 0.1 + 0.2 == 0.3
>>> round(2.675, 2)
>>> round(0.5), round(1.5), round(2.5)
```

---

**🟢 출력 보기**

```text
0.30000000000000004
False
2.67
(0, 2, 2)
```

앞의 둘은 IEEE 754 이진 부동소수점의 숙명입니다. 마지막은 파이썬이 **은행가 반올림**(짝수로 반올림)을 쓰기 때문입니다. 통계적 편향을 줄이는 방식이며, 돈 계산에서는 이 동작이 원치 않는 결과가 될 수 있습니다.

## 돈은 Decimal로

*decimal*

```python
from decimal import Decimal, ROUND_HALF_UP, getcontext

price = Decimal("19.99")          # 반드시 문자열로! Decimal(19.99)는 오차를 그대로 받는다
qty = 3
total = price * qty               # Decimal('59.97')

vat = (total * Decimal("0.1")).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
print(vat)                        # 6.00

getcontext().prec = 28            # 유효숫자 자릿수
```

정확한 분수 연산이 필요하면 `fractions.Fraction`, 부동소수점 비교는 `math.isclose(a, b, rel_tol=1e-9)`를 씁니다.

**⚠️ Gotcha**

`bool`은 `int`의 서브클래스입니다. `True + True == 2`, `sum([True, False, True]) == 2`가 성립하고, `isinstance(True, int)`는 True입니다. dict 키로 쓰면 `1`과 `True`가 **같은 키**가 됩니다.

**🟢 1·2번**

```python
from decimal import Decimal, ROUND_HALF_UP

def total_with_vat(unit_price: str, qty: int) -> Decimal:
    subtotal = Decimal(unit_price) * qty
    return (subtotal * Decimal("1.1")).quantize(Decimal("1"), rounding=ROUND_HALF_UP)
```

2번: `{1: 'c'}`. `1 == True == 1.0`이고 해시값도 같으므로 셋은 동일한 키입니다. 키 객체는 처음 것(`1`)이 유지되고 값만 마지막 것으로 덮어써집니다.
