# 15 · 타입 힌트

`generics · Protocol · TypeVar · mypy`

타입 힌트는 런타임에 **아무것도 강제하지 않습니다**. `__annotations__`에 저장될 뿐이고, 의미는 mypy·pyright 같은 도구와 pydantic 같은 런타임 검증 라이브러리가 부여합니다.

*기본*

```python
def total(items: list[int], rate: float = 0.1) -> int: ...

name: str = "kim"
scores: dict[str, list[int]] = {}
pair: tuple[str, int] = ("a", 1)
row: tuple[int, ...] = (1, 2, 3)         # 길이 가변 동종 튜플

value: int | None = None                 # 3.10+ (구: Optional[int])
handler: Callable[[str, int], bool]
```

**💡 Tip**

인자에는 **넓은 타입**(`Iterable`, `Sequence`, `Mapping`), 반환에는 **좁고 구체적인 타입**(`list`, `dict`)을 쓰세요. 호출부는 유연해지고 사용부는 정확해집니다. 특히 인자 타입에 `list`를 쓰면 튜플·제너레이터를 못 넘깁니다.

*제네릭 · TypeVar*

```python
from typing import TypeVar, Generic, Iterable, Sequence

T = TypeVar("T")

def first(xs: Sequence[T]) -> T | None:
    return xs[0] if xs else None

# 3.12+ 새 문법 — TypeVar 선언 없이
def first[T](xs: Sequence[T]) -> T | None: ...

class Repository[T]:
    def __init__(self) -> None:
        self._items: dict[str, T] = {}
    def get(self, key: str) -> T | None:
        return self._items.get(key)

# 상한 제약
Num = TypeVar("Num", bound=float)
def total(xs: Iterable[Num]) -> Num: ...
```

*실무에서 자주 쓰는 것들*

```python
from typing import (Literal, Final, TypedDict, NotRequired, overload,
                    Self, Never, Any, cast, TYPE_CHECKING)

Mode = Literal["r", "w", "a"]              # 허용 값 자체를 타입으로
MAX_RETRY: Final = 3                        # 재대입 금지

class UserJson(TypedDict):                  # JSON 스키마 표현
    id: int
    name: str
    nickname: NotRequired[str]

class Builder:
    def add(self, x: int) -> Self:          # 체이닝 반환 타입(3.11+)
        return self

if TYPE_CHECKING:                           # 런타임 임포트 없이 타입만
    from .models import Order

def handle(o: "Order") -> None: ...
```

*mypy 설정*

```python
[tool.mypy]
python_version = "3.12"
strict = true                 # 처음엔 부담되면 아래 항목부터 켜세요
warn_unused_ignores = true
disallow_untyped_defs = true
ignore_missing_imports = true
```

**☕ JVM 개발자 노트**

파이썬 제네릭은 JVM처럼 **소거**되는 게 아니라 애초에 런타임에 존재하지 않습니다. `isinstance(x, list[int])`는 `TypeError`입니다. 반면 `list[int]` 객체 자체는 런타임에 만들어져서 `get_type_hints()`로 읽을 수 있고, pydantic·FastAPI가 이걸 이용해 검증·직렬화를 자동화합니다.

**🟢 2·4번**

```python
from typing import overload

@overload
def get(key: str) -> str | None: ...
@overload
def get(key: str, default: str) -> str: ...

def get(key: str, default: str | None = None) -> str | None:
    return STORE.get(key, default)
```

4번: `Any`는 **검사를 끄는** 타입이라 어떤 연산도 통과합니다. `object`는 모든 값을 받지만 **아무 연산도 허용하지 않아** 좁히기(narrowing)를 강제합니다. "무엇이든 받는다"는 의미라면 `object`가 안전합니다.
