# B1 · 변수 — 값에 이름 붙이기

`변수 · 대입 · 이름 규칙`

프로그램은 데이터를 다룹니다. 그 데이터를 나중에 다시 쓰려면 **이름**을 붙여둬야 합니다. 그게 변수입니다.

*변수 만들기*

```python
name = "김파이"
age = 25
height = 172.5

print(name)      # 김파이
print(age)       # 25
```

`=` 기호는 수학의 "같다"가 **아닙니다**. "오른쪽 값을 왼쪽 이름에 넣어라"라는 뜻입니다. `age = 25`는 "25라는 값에 age라는 이름을 붙여라"입니다.

*값은 바뀔 수 있다*

```python
score = 10
print(score)     # 10

score = 20       # 이름표를 새 값에 옮겨 붙임
print(score)     # 20

score = score + 5    # 지금 score(20)에 5를 더해 다시 score로
print(score)     # 25
```

세 번째 줄이 처음엔 이상해 보입니다. 수학에서 `score = score + 5`는 말이 안 되니까요. 하지만 파이썬에서는 **오른쪽을 먼저 계산한 뒤 그 결과를 왼쪽에 넣습니다.** 그래서 "현재 score(20)에 5를 더한 25를 score에 다시 넣어라"가 됩니다.

## 이름 짓는 규칙

- 영문자, 숫자, 밑줄(`_`)을 쓸 수 있습니다. 단 **숫자로 시작할 수 없습니다**. (`2name` ✗, `name2` ✓)
- 띄어쓰기는 안 됩니다. 여러 단어는 밑줄로 잇습니다: `user_name`, `total_price`.
- 대소문자를 구별합니다. `age`와 `Age`는 다른 변수입니다.
- 의미가 드러나는 이름을 쓰세요. `a`보다 `age`가, `x`보다 `total_price`가 훨씬 좋습니다.

**💡 좋은 이름이 좋은 코드다**

변수 이름은 나중의 나와 동료를 위한 배려입니다. `d = 86400`보다 `seconds_per_day = 86400`이 훨씬 친절합니다. 지금부터 이 습관을 들이면 나중에 큰 프로그램을 짤 때 큰 도움이 됩니다.

---

**🟢 3번 답**

```python
# 방법 1: 임시 변수
temp = a
a = b
b = temp

# 방법 2: 파이썬다운 방법 (한 줄로 교환)
a, b = b, a
```

방법 2는 파이썬의 특별한 문법입니다. 오른쪽 `b, a`를 먼저 묶어 계산한 뒤 왼쪽에 한꺼번에 나눠 담습니다. 04파트에서 더 자세히 배웁니다.
