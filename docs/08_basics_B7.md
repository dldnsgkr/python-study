# B7 · == 와 is, 그리고 그다음

`같음의 두 종류 · 심화로 가는 다리`

기초의 마지막입니다. 여기서는 초보자가 반드시 짚어야 할 개념 하나를 확실히 하고, 앞으로 나올 심화 트랙으로 자연스럽게 넘어갑니다.

## == 와 is — "같다"에는 두 종류가 있다

B2에서 `==`가 "값이 같은지" 묻는다고 했습니다. 그런데 파이썬에는 `is`라는 비슷해 보이는 것도 있습니다. 둘은 **완전히 다른 질문**입니다.

- `==` : **값이 같은가?** ("내용이 똑같니?")
- `is` : **완전히 같은 하나인가?** ("이거랑 그거랑 애초에 같은 물건이니?")

*== 와 is의 차이*

```python
a = [1, 2, 3]
b = [1, 2, 3]        # 내용은 같지만 따로 만든 리스트
c = a                # a와 같은 리스트에 c라는 이름표를 하나 더

a == b               # True   내용이 같으니까
a is b               # False  다른 물건이니까 (따로 만들었다)

a == c               # True   내용이 같고
a is c               # True   애초에 같은 하나니까

# c로 바꾸면 a도 바뀐다 (같은 물건이므로)
c.append(4)
print(a)             # [1, 2, 3, 4]  ← a도 바뀜!
```

**⚠️ 실무 규칙 · 값 비교는 무조건 ==**

거의 항상 **`==`를 쓰세요.** 우리가 궁금한 건 보통 "값이 같은가"이기 때문입니다. `is`는 특별한 경우 딱 하나에만 씁니다 — **`None`인지 확인할 때**. `if x is None:`이 표준입니다. (`None`은 "값이 없음"을 나타내는 특별한 값입니다.) 숫자나 문자열 비교에 `is`를 쓰면 가끔 맞다가 가끔 틀리는 이상한 버그가 생기니 피하세요.

이 "이름표"와 "물건"의 구분 — 왜 `c.append(4)`가 `a`까지 바꾸는지 — 는 파이썬을 깊이 이해하는 핵심 열쇠입니다. 지금은 "`=`는 물건을 복사하는 게 아니라 이름표를 붙이는 것"이라는 감만 가지고 넘어가면 됩니다. **심화 트랙(코어 01파트)에서 이걸 그림과 함께 완전히 파헤칩니다.**

## 여기까지 왔다면

축하합니다. 이제 파이썬의 **기본 재료**를 다 손에 넣었습니다.

- 값에 이름 붙이기 (변수)
- 값의 종류 (int·float·str·bool과 list·dict·tuple·set)
- 상황에 따라 행동하기 (if), 반복하기 (for·while)
- 나만의 명령 (함수)과 나만의 타입 (클래스)
- 같음의 두 종류 (== 와 is)

**🟢 3번 예시**

```python
students = [
    {"name": "김파이", "score": 90},
    {"name": "이자바", "score": 85},
    {"name": "박씨플", "score": 78},
]

def average_score(students):
    total = 0
    for student in students:
        total = total + student["score"]
    return total / len(students)

print(f"평균: {average_score(students)}")   # 평균: 84.33...
```

변수·리스트·딕셔너리·for 반복·함수가 모두 들어간, 작지만 완결된 프로그램입니다. 이걸 스스로 만들 수 있다면 기초는 충분합니다.
