# 11 · 특수 메서드 — 언어에 클래스를 끼워 넣기

`dunder · protocol · slots`

파이썬의 모든 문법은 특수 메서드로 되어 있습니다. `len(x)`는 `x.__len__()`, `x[k]`는 `x.__getitem__(k)`, `with x:`는 `x.__enter__()`. 내 클래스에 이 메서드들을 구현하면 **내장 타입과 똑같은 문법으로 동작**합니다. 상속이 아니라 프로토콜입니다.

| 범주 | 메서드 | 트리거 |
| --- | --- | --- |
| 표현 | `__repr__` / `__str__` / `__format__` | 디버깅 출력 / `print` / f-string |
| 비교 | `__eq__ __lt__ __le__ __gt__ __ge__ __ne__` | `== < <=`, `sorted` |
| 해시 | `__hash__` | dict 키, set 원소 |
| 컨테이너 | `__len__ __getitem__ __setitem__ __contains__ __iter__` | `len`, `x[i]`, `in`, `for` |
| 호출 | `__call__` | `obj()` |
| 컨텍스트 | `__enter__ __exit__` | `with` |
| 산술 | `__add__ __radd__ __iadd__ __mul__ …` | `+ += *` |
| 생성/소멸 | `__new__ __init__ __del__` | 인스턴스 생성 |
| 속성 | `__getattr__ __setattr__ __getattribute__ __dir__` | 속성 접근 |
| 비동기 | `__await__ __aenter__ __aiter__ __anext__` | `await`, `async with/for` |

*시퀀스처럼 동작하는 클래스*

```python
class Playlist:
    def __init__(self, tracks): self._tracks = list(tracks)

    def __len__(self):            return len(self._tracks)
    def __getitem__(self, i):     return self._tracks[i]      # 슬라이스도 그대로 위임
    def __contains__(self, t):    return t in self._tracks
    def __repr__(self):           return f"Playlist({self._tracks!r})"

p = Playlist(["a", "b", "c"])
len(p); p[1]; p[::-1]; "b" in p
for t in p: ...        # __iter__ 가 없어도 __getitem__ 만으로 순회 가능(레거시 프로토콜)
```

**💡 Tip**

`__repr__`은 **모든 클래스에 넣으세요.** 로그와 디버거에 ``가 찍히는 것과 `Account(owner='kim', balance=1000)`이 찍히는 것의 차이는 장애 대응 시간에서 갈립니다. 원칙: `repr`은 개발자용(가능하면 재생성 가능한 형태), `str`은 사용자용. `__str__`이 없으면 `__repr__`이 대신 쓰입니다.

## 컨텍스트 매니저

*with 프로토콜*

```python
class Transaction:
    def __init__(self, conn): self.conn = conn

    def __enter__(self):
        self.conn.begin()
        return self                       # as 뒤에 바인딩될 값

    def __exit__(self, exc_type, exc, tb):
        if exc_type is None:
            self.conn.commit()
        else:
            self.conn.rollback()
        return False                      # True를 반환하면 예외가 삼켜진다!

# 제너레이터로 훨씬 간단하게
from contextlib import contextmanager

@contextmanager
def transaction(conn):
    conn.begin()
    try:
        yield conn
    except Exception:
        conn.rollback()
        raise
    else:
        conn.commit()
```

*contextlib 도구들*

```python
from contextlib import suppress, closing, ExitStack, nullcontext

with suppress(FileNotFoundError):
    os.remove(path)                       # try/except/pass 를 한 줄로

with ExitStack() as stack:                # 개수가 동적인 리소스
    files = [stack.enter_context(open(p)) for p in paths]
```

## __slots__ — 메모리와 오타 방지

*slots*

```python
class Point:
    __slots__ = ("x", "y")        # __dict__ 를 만들지 않는다
    def __init__(self, x, y):
        self.x, self.y = x, y

p = Point(1, 2)
p.z = 3        # AttributeError — 선언되지 않은 속성 차단
```

인스턴스를 수십만 개 만드는 경우 메모리가 크게 줄고 속성 접근도 조금 빨라집니다. 대신 동적 속성 추가와 다중 상속에 제약이 생깁니다.

**🖥 REPL 퀴즈 — 11-1 · 특수 메서드 조회 경로**

```python
>>> class C: pass
>>> c = C()
>>> c.__len__ = lambda: 42
>>> c.__len__()
>>> len(c)
```

---

**🟢 출력 보기**

```text
42
TypeError: object of type 'C' has no len()
```

특수 메서드는 **인스턴스가 아니라 타입에서** 조회됩니다. 이는 성능 최적화이자, 모든 인스턴스가 같은 문법 동작을 갖도록 하는 보장이기도 합니다. 몽키패칭을 하려면 `C.__len__ = ...`처럼 클래스에 붙여야 합니다.

### 🏋 DRILL 11 — 특수 메서드

1. `Money` 클래스를 만들어 같은 통화끼리만 `+`, `-`, 비교가 되게 하고 다른 통화면 `TypeError`를 내세요. `__radd__`도 구현해 `sum()`이 동작하게 하세요.
2. 임시 디렉터리를 만들고 블록을 벗어나면 지우는 컨텍스트 매니저를 클래스와 `@contextmanager` 두 방식으로 작성하세요.
3. `__exit__`가 `True`를 반환하도록 만들어 예외가 삼켜지는 것을 확인한 뒤, 왜 이것이 위험한지 쓰세요.
4. 같은 데이터를 담은 일반 클래스와 `__slots__` 클래스를 각각 100만 개 만들어 메모리 사용량을 비교하세요(`tracemalloc`).

**🟢 1번 핵심**

```python
from functools import total_ordering

@total_ordering                      # __eq__ 와 __lt__ 만 있으면 나머지를 채워 준다
class Money:
    __slots__ = ("amount", "currency")

    def __init__(self, amount: int, currency: str = "KRW"):
        self.amount, self.currency = amount, currency

    def _check(self, other):
        if not isinstance(other, Money) or other.currency != self.currency:
            raise TypeError("통화가 다릅니다")

    def __eq__(self, other):
        return (isinstance(other, Money) and self.currency == other.currency
                and self.amount == other.amount)

    def __lt__(self, other):
        self._check(other); return self.amount < other.amount

    def __add__(self, other):
        self._check(other); return Money(self.amount + other.amount, self.currency)

    def __radd__(self, other):
        return self if other == 0 else self.__add__(other)   # sum()은 0에서 시작한다

    def __hash__(self):   return hash((self.amount, self.currency))
    def __repr__(self):   return f"Money({self.amount}, {self.currency!r})"
```
