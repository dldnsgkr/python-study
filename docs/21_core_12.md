`dataclass · Enum · ABC · Protocol`

## dataclass

*dataclasses*

```python
from dataclasses import dataclass, field, asdict, replace

@dataclass(frozen=True, slots=True, kw_only=True)
class Order:
    id: str
    items: list[str] = field(default_factory=list)   # 가변 기본값은 반드시 factory
    memo: str | None = None
    _cache: dict = field(default_factory=dict, repr=False, compare=False)

    def total(self) -> int: ...

o = Order(id="A1", items=["x"])
asdict(o)                    # 중첩까지 dict로
replace(o, memo="급함")       # 불변 객체의 부분 수정 → 새 객체
```

| 옵션 | 효과 |
| --- | --- |
| `frozen=True` | 대입 금지 + `__hash__` 자동 생성 |
| `slots=True` | `__slots__` 생성(3.10+) |
| `kw_only=True` | 모든 필드를 키워드 전용으로 — 필드 추가 시 순서 사고 방지 |
| `order=True` | 비교 연산자 생성(필드 선언 순서 기준) |

**⚠️ Gotcha**

`items: list[str] = []`라고 쓰면 dataclass가 `ValueError`로 즉시 막아 줍니다(07파트의 가변 기본값 함정을 언어 차원에서 방지). 반드시 `field(default_factory=list)`를 쓰세요. 단, `dict`를 기본값 **타입**으로 두는 커스텀 클래스는 막아 주지 못합니다.

**☕ JVM 개발자 노트**

`@dataclass(frozen=True)` ≈ Kotlin `data class` + `val` ≈ Java `record`. 검증까지 필요하면 `__post_init__`을 쓰거나, 외부 입력(HTTP 요청/JSON)에는 **pydantic**을 쓰는 게 실무 표준입니다. pydantic은 타입 힌트를 런타임 검증으로 강제해 줍니다.

## Enum

*enum*

```python
from enum import Enum, StrEnum, IntEnum, auto, Flag

class Status(StrEnum):        # 3.11+: str 서브클래스라 JSON 직렬화가 자연스럽다
    PENDING = "pending"
    PAID = "paid"
    CANCELED = "canceled"

Status("paid")                # 값으로 조회
Status.PAID.name, Status.PAID.value
list(Status)                  # 선언 순서대로 순회

class Perm(Flag):
    READ = auto(); WRITE = auto(); EXEC = auto()

p = Perm.READ | Perm.WRITE
Perm.WRITE in p               # True
```

## 추상 기반 클래스 vs 프로토콜

*ABC (명시적 상속)*

```python
from abc import ABC, abstractmethod

class Repository(ABC):
    @abstractmethod
    def get(self, id: str) -> dict: ...

    def get_or_raise(self, id):        # 구현 공유 가능
        if (v := self.get(id)) is None:
            raise KeyError(id)
        return v

class SqlRepository(Repository):       # 반드시 상속해야 한다
    def get(self, id): ...
```

*Protocol (구조적 타이핑)*

```text
from typing import Protocol, runtime_checkable

@runtime_checkable
class Closeable(Protocol):
    def close(self) -> None: ...

def cleanup(resource: Closeable) -> None:
    resource.close()

# 상속 선언이 전혀 없어도 close()만 있으면 타입 체커가 통과시킨다
```

정리: **구현을 공유하고 상속 관계를 강제하고 싶으면 ABC**, **남이 만든 타입까지 포함해 "모양만 맞으면 된다"면 Protocol**. 파이썬 문화는 후자(덕 타이핑)에 가깝고, Protocol은 그 덕 타이핑에 정적 검사를 붙인 것입니다.

**🟢 1·2번 예시 답**

```python
from dataclasses import dataclass

@dataclass(frozen=True, kw_only=True)
class OrderLine:
    sku: str
    qty: int
    unit_price: int

    def __post_init__(self):
        if self.qty <= 0:
            raise ValueError("수량은 1 이상이어야 합니다")
        if self.unit_price < 0:
            raise ValueError("단가는 음수일 수 없습니다")

TRANSITIONS = {
    Status.PENDING: {Status.PAID, Status.CANCELED},
    Status.PAID: {Status.CANCELED},
    Status.CANCELED: set(),
}

def transition(current: Status, nxt: Status) -> Status:
    if nxt not in TRANSITIONS[current]:
        raise ValueError(f"{current} → {nxt} 전이 불가")
    return nxt
```

frozen dataclass에서 `__post_init__` 안에 값을 **대입**하려면 `object.__setattr__(self, "field", value)`를 써야 합니다. 검증만 한다면 문제없습니다.
