# B2 · 기본 데이터 타입 — 값의 종류

`정수 · 실수 · 문자열 · 불리언`

파이썬이 다루는 데이터에는 **종류(타입)**가 있습니다. 숫자와 글자를 다르게 다뤄야 하니까요. 가장 기본이 되는 네 가지부터 봅니다.

| 타입 | 영어 이름 | 예시 | 무엇 |
| --- | --- | --- | --- |
| 정수 | `int` | `0`, `25`, `-7` | 소수점 없는 수 |
| 실수 | `float` | `3.14`, `-0.5`, `2.0` | 소수점 있는 수 |
| 문자열 | `str` | `"안녕"`, `"a"` | 글자(들). 따옴표로 감쌈 |
| 불리언 | `bool` | `True`, `False` | 참/거짓 딱 두 개 |

*타입 확인하기*

```python
type(25)          # <class 'int'>
type(3.14)        # <class 'float'>
type("안녕")       # <class 'str'>
type(True)        # <class 'bool'>
```

`type()`은 "이 값의 종류가 뭐야?"라고 묻는 명령입니다. 헷갈릴 때 언제든 써서 확인할 수 있습니다.

## 정수와 실수 — 숫자 두 종류

*숫자 연산*

```python
3 + 5        # 8    더하기
10 - 4       # 6    빼기
6 * 7        # 42   곱하기
15 / 4       # 3.75 나누기 (결과는 항상 실수!)
15 // 4      # 3    몫만 (버림 나눗셈)
15 % 4       # 3    나머지
2 ** 10      # 1024 거듭제곱 (2의 10제곱)
```

**⚠️ 주의 · 나눗셈은 실수가 된다**

`10 / 2`는 `5`가 아니라 `5.0`입니다. 파이썬에서 `/`는 항상 실수(float)를 만듭니다. 소수점 없는 몫이 필요하면 `//`를 쓰세요. `10 // 3`은 `3`, `10 % 3`은 나머지 `1`입니다. `%`(나머지)는 "짝수인가?"(`n % 2 == 0`) 같은 판단에 자주 씁니다.

## 문자열 — 글자 다루기

*문자열 기본*

```python
greeting = "안녕하세요"
name = "김파이"

# 이어붙이기 (+)
message = greeting + ", " + name       # "안녕하세요, 김파이"

# 반복하기 (*)
line = "=" * 20                         # "===================="

# 길이 재기
len(name)                               # 3 (글자 수)

# 파이썬다운 방법: f-문자열 (변수를 문장에 끼워넣기)
age = 25
info = f"{name}님은 {age}살입니다"      # "김파이님은 25살입니다"
```

마지막 **f-문자열**이 특히 유용합니다. 따옴표 앞에 `f`를 붙이고, 문장 안에 `{변수}`를 넣으면 그 자리에 변수 값이 채워집니다. 문자열을 `+`로 잇는 것보다 훨씬 읽기 쉽습니다.

**⚠️ 주의 · 숫자와 글자는 못 더한다**

`"나이: " + 25`는 오류입니다. 글자와 숫자를 직접 더할 수 없습니다. 두 방법 중 하나를 쓰세요. ① f-문자열: `f"나이: {25}"`, ② 숫자를 글자로 변환: `"나이: " + str(25)`. `str()`은 숫자를 글자로 바꾸는 명령입니다.

## 불리언 — 참과 거짓

`True`(참)와 `False`(거짓)는 단 두 개뿐인 특별한 값입니다. "예/아니오"로 답할 수 있는 모든 것이 여기 해당합니다. 비교 연산의 결과가 바로 불리언입니다.

*비교하면 불리언이 나온다*

```python
5 > 3            # True
10 == 10         # True   (== 는 '같은가?' 물음. = 대입과 다름!)
10 != 5          # True   (!= 는 '다른가?')
3 >= 5           # False
"a" == "a"       # True
```

**⚠️ 가장 흔한 실수 · = 와 ==**

`=`는 **대입**(값 넣기), `==`는 **비교**(같은지 묻기)입니다. `age = 25`는 "age에 25를 넣어라", `age == 25`는 "age가 25와 같니?"입니다. 초보자가 가장 많이 헷갈리는 부분이니 지금 확실히 해두세요.

## 타입 변환

*타입 바꾸기*

```python
int("25")        # 25    글자 "25" → 숫자 25
str(25)          # "25"   숫자 25 → 글자 "25"
float("3.14")    # 3.14  글자 → 실수
int(3.9)         # 3     실수 → 정수 (소수점 버림, 반올림 아님!)

# 사용자 입력은 항상 문자열로 들어온다
user_age = input("나이를 입력하세요: ")    # "25" (글자!)
user_age = int(user_age)                    # 25 (숫자로 변환해야 계산 가능)
```

**💡 input은 항상 글자**

`input()`으로 받은 값은 사용자가 숫자를 입력해도 **글자(str)**입니다. 계산에 쓰려면 `int()`나 `float()`로 변환해야 합니다. 이걸 잊으면 `"25" + 5` 같은 오류를 만나게 됩니다.
