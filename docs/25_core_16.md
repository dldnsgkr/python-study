## pathlib — os.path는 잊으세요

*pathlib*

```python
from pathlib import Path

root = Path(__file__).resolve().parent
config = root / "conf" / "app.toml"        # / 연산자로 경로 조합

config.exists(); config.stem; config.suffix; config.name
config.read_text(encoding="utf-8")
config.write_text(data, encoding="utf-8")

for p in root.rglob("*.py"):               # 재귀 글롭
    print(p.relative_to(root))

(root / "out").mkdir(parents=True, exist_ok=True)
```

## datetime — 타임존을 붙이세요

*datetime*

```python
from datetime import datetime, date, timedelta, timezone, UTC
from zoneinfo import ZoneInfo

seoul = ZoneInfo("Asia/Seoul")

now = datetime.now(UTC)                     # aware — 권장
local = now.astimezone(seoul)

dt = datetime.fromisoformat("2026-07-24T10:30:00+09:00")
dt.isoformat()
dt.strftime("%Y-%m-%d %H:%M")
```

**⚠️ Gotcha**

naive(타임존 없는) `datetime`과 aware를 비교하면 `TypeError`입니다. 원칙: **저장·전송·비교는 UTC aware로, 표시할 때만 로컬 타임존으로 변환.** `utcnow()`는 naive를 돌려주므로 쓰지 말고 `datetime.now(UTC)`를 쓰세요.

## json

*json*

```python
import json

json.dumps(obj, ensure_ascii=False, indent=2, default=str)   # 한글 그대로, 미지원 타입은 str로
json.loads(text)

with open(path, encoding="utf-8") as f:
    data = json.load(f)

class Encoder(json.JSONEncoder):        # 커스텀 직렬화
    def default(self, o):
        if isinstance(o, datetime): return o.isoformat()
        if isinstance(o, Decimal):  return str(o)
        return super().default(o)
```

## re — 정규식

*re*

```python
import re

PATTERN = re.compile(r"(?P<year>\d{4})-(?P<month>\d{2})")   # 미리 컴파일 + 이름 있는 그룹

if m := PATTERN.search(text):
    m.group("year"); m.groupdict()

re.findall(r"\w+@\w+\.\w+", text)
re.sub(r"\s+", " ", text)
re.split(r"[,;]\s*", text)

# 항상 raw string(r"...")을 쓰고, 여러 줄 패턴은 re.VERBOSE로 주석을 답니다
```

## logging

*logging*

```python
import logging

logger = logging.getLogger(__name__)      # 모듈별 로거 — 관례

logger.info("주문 처리 %s", order_id)      # % 포맷을 인자로! f-string은 항상 문자열을 만든다
logger.exception("실패")                   # except 블록 안에서: 트레이스백 자동 첨부

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(name)s %(message)s",
)
```

**💡 Tip**

라이브러리·모듈 코드에서는 `basicConfig`를 호출하지 마세요. 핸들러 설정은 **애플리케이션 진입점의 책임**입니다. 모듈은 `getLogger(__name__)`으로 로거를 얻어 쓰기만 합니다.

**🟢 3번 힌트**

```python
from datetime import datetime, timedelta, time, UTC
from zoneinfo import ZoneInfo

def yesterday_range_utc(tz="Asia/Seoul"):
    z = ZoneInfo(tz)
    today_local = datetime.now(z).date()
    y = today_local - timedelta(days=1)
    start = datetime.combine(y, time.min, tzinfo=z)
    end = datetime.combine(y + timedelta(days=1), time.min, tzinfo=z)
    return start.astimezone(UTC), end.astimezone(UTC)   # [start, end) 반열린 구간
```

23:59:59로 끝을 잡으면 그 사이 1초를 놓칩니다. 시간 범위는 언제나 **반열린 구간 [start, end)**으로 다루세요.
