# 03 · 문자열과 바이트

`unicode · encode/decode · f-string · format spec`

파이썬 3의 핵심 구분: `str`은 **유니코드 코드포인트의 시퀀스**, `bytes`는 **0~255 정수의 시퀀스**입니다. 둘 사이는 반드시 인코딩을 거칩니다. 암묵적 변환은 없습니다.

*str ↔ bytes*

```python
s = "한글"
b = s.encode("utf-8")     # b'\xed\x95\x9c\xea\xb8\x80'
len(s), len(b)            # (2, 6)  ← 문자 수와 바이트 수는 다르다
b.decode("utf-8")         # '한글'

"café".encode("ascii")    # UnicodeEncodeError
b"\xff".decode("utf-8")   # UnicodeDecodeError
b"\xff".decode("utf-8", errors="replace")   # '\ufffd'
```

**💡 Tip**

파일을 열 때는 인코딩을 **항상 명시**하세요. `open(path, encoding="utf-8")`. 명시하지 않으면 OS 로케일을 따라가서 Windows 환경(cp949)에서만 깨지는 버그가 생깁니다.

## f-string: 포맷 미니 언어

*f-string*

```python
name, amount, ratio = "결제", 1234567.891, 0.4567

f"{name}: {amount:,.2f}원"      # '결제: 1,234,567.89원'
f"{ratio:.1%}"                   # '45.7%'
f"{42:>8}|{42:<8}|{42:^8}"       # 오른쪽/왼쪽/가운데 정렬
f"{255:#x} {255:08b}"            # '0xff 11111111'
f"{amount=}"                     # 'amount=1234567.891'  ← 디버깅용
f"{name!r}"                      # "'결제'"  ← repr() 적용

from datetime import datetime
f"{datetime.now():%Y-%m-%d %H:%M}"   # 객체별 __format__ 규칙 사용
```

포맷 스펙 문법: `[[fill]align][sign][#][0][width][,][.precision][type]`

## 자주 쓰는 str 메서드

| 메서드 | 설명 |
| --- | --- |
| `strip() / lstrip() / rstrip()` | 공백(또는 지정 문자) 제거 |
| `split(sep, maxsplit) / rsplit()` | 인자 없으면 연속 공백 기준 분리 |
| `partition(sep)` | `(앞, 구분자, 뒤)` 3-튜플 — 파싱에 안전 |
| `"".join(iterable)` | 연결의 정석. `+=` 루프보다 훨씬 빠름 |
| `startswith(tuple)` | 튜플을 받아 여러 개 동시 검사 가능 |
| `removeprefix() / removesuffix()` | 3.9+. `strip()`과 혼동 금지 |
| `casefold()` | `lower()`보다 강한 대소문자 무시 비교 |

**⚠️ Gotcha**

`"banana".strip("ba")`는 `"n"`입니다. `strip`의 인자는 **제거할 문자 집합**이지 접두사가 아닙니다. 접두사 제거에는 `removeprefix("ba")`를 쓰세요.

**🖥 REPL 퀴즈 — 03-1 · 문자열 정체성**

```python
>>> s = "hello"
>>> t = "hel" + "lo"
>>> s is t
>>> u = "".join(["hel", "lo"])
>>> s is u
>>> s == u
```

---

**🟢 출력 보기**

```text
True
False
True
```

`"hel" + "lo"`는 컴파일 타임에 상수 폴딩되어 인터닝된 같은 객체가 됩니다. 런타임 `join` 결과는 새 객체입니다. Java의 문자열 리터럴 풀과 같은 이야기이고, 결론도 같습니다 — 문자열 비교에 `is`를 쓰지 마세요.

**🟢 1·2번**

```python
s = "key=value=extra"
k, _, v = s.partition("=")        # ('key', 'value=extra')
k, v = s.split("=", 1)            # 같은 결과

rows = [("커피", 4500.0), ("샌드위치", 8900.5)]
for name, amount in rows:
    print(f"{name:<12}{amount:>10,.2f}")
```

한글은 폭이 두 배라 `<12` 정렬이 시각적으로 어긋납니다. 실무에서는 `unicodedata.east_asian_width`로 실제 폭을 계산하거나 `wcwidth` 패키지를 씁니다.
