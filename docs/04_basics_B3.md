# B3 · 여러 값 담기 — 리스트·튜플·딕셔너리·세트

`컬렉션 타입 입문`

지금까지는 값 하나에 이름 하나였습니다. 그런데 "학생 30명의 점수"처럼 **여러 값을 묶어** 다뤄야 할 때가 많습니다. 그때 쓰는 네 가지 그릇을 배웁니다. 각각 성격이 다릅니다.

| 타입 | 모양 | 순서 | 변경 | 언제 쓰나 |
| --- | --- | --- | --- | --- |
| 리스트 `list` | `[1, 2, 3]` | 있음 | 가능 | 순서 있는 값 묶음(가장 많이 씀) |
| 튜플 `tuple` | `(1, 2, 3)` | 있음 | 불가 | 바뀌면 안 되는 값 묶음 |
| 딕셔너리 `dict` | `{"a": 1}` | 있음 | 가능 | 이름표-값 짝(사전처럼) |
| 세트 `set` | `{1, 2, 3}` | 없음 | 가능 | 중복 없는 모음 |

## 리스트 — 가장 자주 쓰는 그릇

*리스트 기본*

```python
scores = [90, 85, 77, 92]

# 꺼내기 (0부터 센다! 첫 번째가 0번)
scores[0]        # 90  (첫 번째)
scores[1]        # 85  (두 번째)
scores[-1]       # 92  (맨 마지막)

# 바꾸기
scores[0] = 100  # 첫 번째를 100으로

# 추가하기
scores.append(88)        # 맨 뒤에 88 추가 → [100, 85, 77, 92, 88]

# 개수 세기
len(scores)              # 5

# 들어있는지 확인
90 in scores             # True (90이 리스트에 있나?)
```

**⚠️ 중요 · 순서는 0부터 센다**

프로그래밍에서는 첫 번째가 **0번**입니다. `scores[0]`이 첫 번째, `scores[1]`이 두 번째입니다. 처음엔 어색하지만 모든 언어의 공통 규칙이니 익숙해지세요. 맨 마지막은 `scores[-1]`로 편하게 꺼낼 수 있습니다.

## 딕셔너리 — 이름표로 값 찾기

리스트가 "순서(번호)로 값을 찾는다"면, 딕셔너리는 **"이름(키)으로 값을 찾습니다"**. 진짜 사전처럼요 — 단어를 찾으면 뜻이 나오듯이.

*딕셔너리 기본*

```python
person = {
    "name": "김파이",
    "age": 25,
    "city": "서울",
}

# 이름(키)으로 값 꺼내기
person["name"]           # "김파이"
person["age"]            # 25

# 값 바꾸기 / 새로 추가
person["age"] = 26           # 나이 수정
person["job"] = "개발자"      # 새 항목 추가

# 키가 있는지 확인
"name" in person             # True
```

딕셔너리는 실무에서 정말 많이 씁니다. 사람 정보, 설정값, 웹에서 주고받는 데이터(JSON)가 전부 이 형태입니다. AI·데이터 작업에서도 계속 만나게 됩니다.

## 튜플과 세트 — 간단히

*튜플·세트*

```python
# 튜플: 바뀌지 않는 리스트. 좌표처럼 고정된 짝에 좋다
point = (37.5, 127.0)        # 위도, 경도
point[0]                     # 37.5
# point[0] = 0   ← 오류! 튜플은 못 바꾼다

# 세트: 중복이 자동으로 사라지는 모음
numbers = {1, 2, 2, 3, 3, 3}
print(numbers)               # {1, 2, 3}  중복 제거됨

# 리스트의 중복 제거에 유용
names = ["김", "이", "김", "박"]
unique = set(names)          # {"김", "이", "박"}
```

**💡 언제 무엇을?**

고민되면 **리스트**로 시작하세요. 순서가 있고 자유롭게 바꿀 수 있어 가장 무난합니다. 이름표로 찾고 싶으면 **딕셔너리**, 절대 안 바뀌어야 하면 **튜플**, 중복을 없애고 싶으면 **세트**입니다. 이 감각은 쓰다 보면 자연스럽게 생깁니다.
